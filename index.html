Grainlink

Web-based point-of-sale and management system for Wilmar's Merchandise.

In progress

Overview

Grainlink is a capstone proposal for Wilmar's Merchandise, a local business that still records many sales by hand. The system combines a point-of-sale, inventory tracking, automated sales reports, and real-time delivery tracking in one web application.

Key features

  • Point-of-sale with receipts and purchase records
  • Inventory tracking with stock updates
  • Automated daily and monthly sales reports
  • Real-time delivery tracking

What I did and learned

  • Surveyed customers to find the problems in the current process
  • Wrote the background and problem statement (Chapter 1)
  • Learned to turn survey results into system requirements

Tools

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL
